# Free books for Jacket

These books are in the public domain everywhere in the world, so anyone can read and share them for free. The files live on the [Free books for Jacket release](https://github.com/friendlyglobal/jacket/releases/tag/books).

**How to use it:** tap a book's title. It downloads in your browser. Then open the file with Jacket.

**Languages:** [English](#english) (7) · [Español](#español) (8) · [Português (Brasil)](#português-brasil) (15) · [Français](#français) (8) · [Italiano](#italiano) (7) · [Deutsch](#deutsch) (8) · [Nederlands](#nederlands) (5) · [Polski](#polski) (7) · [Русский](#русский) (7) · [Українська](#українська) (6) · [العربية](#العربية) (8) · [Bahasa Indonesia](#bahasa-indonesia) (2) · [日本語](#日本語) (8) · [한국어](#한국어) (4) · [简体中文](#简体中文) (6) · [繁體中文](#繁體中文) (8)

## About these files

- **Standard Ebooks** files are unchanged and dedicated to the public domain (CC0).
- **Project Gutenberg** files are unchanged, with the Project Gutenberg License inside.
- **Wikisource** files keep their credits page and are shared under CC BY-SA 3.0. We removed the large embedded fonts and tidied the title and author. The 简体中文 books were converted from Traditional to Simplified characters with OpenCC. Each file notes these changes on its credits page.
- **Wolne Lektury** texts are in the public domain. Their footnotes and themes are under the Free Art License 1.3, as stated inside each file.
- Every author, translator and artist of these works died in 1925 or earlier, and every work was first published before 1930. Footnotes added by Wikisource volunteers or Wolne Lektury editors are shared under the open licences above.
- File sizes and SHA-256 checksums are in [`books/catalog.json`](https://github.com/friendlyglobal/jacket/blob/main/books/catalog.json).
